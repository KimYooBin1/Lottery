# 웹캠 손가락 뽑기 게임 MVP 설계 문서

원본 설계는 로컬 작업 문서에서 정리했고, 구현 기준 요약만 저장한다.

## 핵심 요구사항

- 데스크톱 웹 브라우저에서 동작
- 웹캠 기반 검지 단위 참여
- 참여자는 화면에 보이는 검지로만 참여
- 당첨 인원 수 설정 가능
- 검지 집합 변화 시 카운트다운 리셋
- 결과 이미지를 합성해 저장/공유

## 구현 방향

- React + TypeScript + Vite
- MediaPipe Hands 기반 손 랜드마크 추론
- 검지 끝 후보 추출 후 활성 객체 추적
- 상태 머신으로 카메라 준비, 안정화, 카운트다운, 결과 상태 관리
- GitHub Actions로 GitHub Pages 배포

## MVP 범위 메모

현재 구현은 MediaPipe Hands의 검지 끝 랜드마크만 사용한다. `FingerType`에는 다른 손가락 타입이 남아 있지만 확장 여지를 위한 타입이며, MVP 게임 규칙은 검지 전용이다.
